# RSSSF reply (2026-10-16)

Reply received by Diego Estela Lopez from an RSSSF contact (first name only, as signed), in answer to the request drafted in `docs/spike/permission-requests.md` (section 1). Contact details were removed from this copy because the repository is public.

The request asked for permission to: (1) store the match results and final tables of the Argentine first division in the public repository of the project, with a per-record source field; (2) show statistics derived from them in a free, non-commercial web app; (3) credit RSSSF and the page authors as they prefer.

> yes, 1, 2 and 3 are all okay. As for the credit, assuming for instance Osvaldo José Gorgazzi is the relevant author, something like: "Many thanks to Osvaldo José Gorgazzi and RSSSF for providing this information" would be fine, possibly with a link to the main RSSSF page or the page you used.
>
> Karel

## Scope and how we apply it

- Permission is for what was requested: Argentine first division results and final tables. Anything else needs a new written answer.
- Every record taken from RSSSF keeps the URL of the page used in its `source` field.
- `/acerca` shows the credit line with the author of the page used and a link to RSSSF.
