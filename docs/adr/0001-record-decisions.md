# 0001 — Record architecture decisions

## Context

The project is built largely by AI agents under human supervision. Decisions must leave a written trail that survives between sessions.

## Decision

Every architecture decision is recorded as a short ADR in `docs/adr/` (Context / Decision / Consequences), numbered sequentially and written in English.

## Consequences

Reviewers and agents can check why something is the way it is. Reversing a decision means writing a new ADR that supersedes the old one.
