# 0005 — No official crests

## Context

Official crests, trophies and photos are protected intellectual property.

## Decision

Each club gets a **generic SVG crest** generated from its colors, jersey pattern (solid, stripes, band...) and initials. Trophies are our own generic SVG illustrations per cup type. No match, player or stadium photos with rights.

## Consequences

Crests are recognizable by color without using any trademark. A `Crest` component takes the club's color tokens and pattern as input.
